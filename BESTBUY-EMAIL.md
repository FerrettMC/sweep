## Notes before you send

- **Send it from `support@sweepshopping.com`**, the address you used on 15 Aug,
  so it threads with the original if anyone ever does find it.
- **Check the 28 August date** — change it if you called on a different day.
- **The three numbered asks are the important part.** Point 3 especially: giving
  them permission to say no is what stops this sitting in a queue forever, and
  a definite no lets you spend the effort on Zappos instead.
- **Keep a copy of the sent mail.** If you do call again, "I emailed
  developer@ on the 28th and had no reply" is the sentence that gets escalated.

## If they don't reply in 3 days

Call, and lead with this rather than re-explaining:

> "I've contacted Best Buy four times since 15 August about developer API
>  access — twice by email, twice by phone. Nobody has been able to find a
>  record of any of it. I'd like a reference number, or to be told plainly that
>  these keys aren't issued any more."

Ask for a supervisor if the person can't create a ticket. The thing you need
isn't sympathy, it's a reference number — without one, every contact starts from
zero, which is exactly what has happened three times.
